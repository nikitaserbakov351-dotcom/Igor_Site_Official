# Персональный сайт-визитка на Flask

Небольшой пет-проект: адаптивный мультимедийный лендинг с встроенным аудиоплеером, написанный на Flask без использования тяжелых сторонних фреймворков. 

Изначально делал проект для отработки адаптивной верстки, работы со статикой и потоковым воспроизведением медиа через чистый HTML5/CSS/JS.

## Что внутри
- Легковесный бэкенд на Flask (шаблон встроен прямо в скрипт для автономного запуска в один файл).
- Адаптивный интерфейс: Flexbox, CSS Grid и базовый JS для мобильного бургер-меню.
- Секция плеера под локальные mp3-треки (работает без внешних библиотек).
- Утилита под сокеты в `__main__`: при старте скрипт сам определяет локальный IP машины в Wi-Fi сети и печатает адрес в консоль, чтобы можно было быстро проверить верстку со смартфона.

## Приватность и медиафайлы
Все оригинальные фотографии, видеозаписи и реальные контакты были намеренно удалены из публичной ветки репозитория ради конфиденциальности. В соответствующих блоках (галерея и видео) оставил информационные заглушки, чтобы не ломать разметку и логику навигации.
